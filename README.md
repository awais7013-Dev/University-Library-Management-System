# Project Overview

The University Library Management System (ULMS) is a software engineering project created to improve the management of library operations at a university. Currently, book borrowing, returns, student membership, and overdue records are managed manually or through an outdated system.

The proposed system aims to provide an organized and efficient solution for managing books, members, borrowing activities, returns, reservations, and overdue notifications.

This project focuses on requirements analysis, system modeling, project planning, and user interface design. Full software implementation is not included in the project scope.

---

# Project Scope

The system will support the following functions:

- Book catalog management
- Student membership management
- Borrowing and returning books
- Book reservation services
- Overdue book tracking
- Notification management
- Library administration functions

### Out of Scope

- Online payment processing
- Mobile application development
- Integration with external library systems
- Complete software implementation

---

# Project Objectives

1. Improve the efficiency of library operations.
2. Reduce manual record\-keeping.
3. Provide quick access to library information.
4. Track borrowed and overdue books accurately.
5. Improve user experience for students and librarians.
6. Provide a structured foundation for future system development.

---

# Assumptions

- All students have valid university IDs.
- Library staff will maintain book records.
- Users have internet access to use the system.
- Library data is accurate and up to date.
- Notification services are available for overdue alerts.

---

# Constraints

- Limited project duration.
- Limited resources and budget.
